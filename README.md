#  Сапёр (Minesweeper)

## Описание
Классическая игра-головоломка «Сапёр», реализованная на платформе Windows Forms с помощью языка программированияC#. Проект представляет собой оконное приложение с интерфейсом, системой выбора сложности, таймером и функцией сохранения рекордов. Игроку необходимо открыть все клетки игрового поля, не задев мины. Числа на открытых клетках показывают общее количество мин в соседних клетках, а пустые клетки автоматически открывают соседние области. Игра завершается победой, когда все безопасные клетки открыты, а поражением когда игрок задевает мину.

## Основные функции и возможности
Приложение «Сапёр» имеет следующий функционал:
- **Выбор уровня сложности:** Новичок (10 мин), Любитель (13 мин), Профессионал (16 мин), Мастер (52 мины).
- **Игровой процесс:**
  - Левая кнопка мыши: открытие клетки.
  - Правая кнопка мыши: установка или снятие флажка (двойным кликом правой кнопки мыши).
  - Рекурсивное открытие пустых клеток (автоматическое открытие всех соседних пустых областей).
- **Таймер:** Отсчёт времени начинается с первого клика по полю.
- **Статистика и рекорды:**
  - Сохранение лучшего времени для каждого уровня сложности.
  - Подсчёт общего количества игр, побед и поражений.
  - Данные сохраняются в файл `records.json` в формате JSON.
- **Визуализация:** Все элементы отображаются с помощью графических файлов (`.png`).

## Отличительные особенности
- **Гарантированно безопасный первый ход:** Мины генерируются только после первого клика, исключая проигрыш на первом шаге.
- **Человекочитаемые рекорды:** Файл `records.json` содержит названия полей на русском языке, что делает его понятным для конечного пользователя.
- **Архитектура проекта:** Код разделён на логические классы, что упрощает его поддержку и развитие.

#### 3. Аннотация
Проект представляет собой приложение для игры в «Сапёр», разработанное на языке программирования C# с использованием Windows Forms. Приложение включает в себя выбор сложности, игровое поле 9x9, систему флажков, таймер и ведение статистики с сохранением рекордов в JSON-файл. Цель проекта — создание полноценной, стабильной и удобной версии классической игры с возможностью демонстрации навыков объектно-ориентированного программирования и работы с файловой системой.

#### 4. Техническое задание

##### 4.1. Назначение разработки
- Обеспечение понятного и отзывчивого пользовательского интерфейса.
- Реализация всех ключевых игровых механик: генерация поля, подсчёт мин, рекурсивное открытие клеток.
- Добавление системы сохранения лучших результатов для мотивации игрока.

##### 4.2. Целевая аудитория
- Пользователи операционной системы Windows, желающие поиграть в классическую игру-головоломку.
- Преподаватели и студенты, изучающие основы программирования на C# и Windows Forms.

##### 4.3. Требования к программе
1.  **Игровое поле:**
    - Размер поля: фиксированный 9x9.
    - Каждая клетка может содержать мину, быть пустой или содержать цифру от 1 до 4.
    - Клетки могут быть закрыты, открыты или помечены флажком.
2.  **Генерация мин:**
    - Мины генерируются случайным образом после первого клика игрока.
    - Первый клик всегда безопасен (клетка и её соседи гарантированно не содержат мины).
3.  **Логика игры:**
    - При клике по клетке с миной — игра заканчивается поражением, все мины показываются.
    - При клике по пустой клетке (0 мин рядом) — она открывается, и рекурсивно открываются все соседние пустые клетки.
    - При клике по клетке с цифрой — открывается только она, показывая количество мин вокруг.
4.  **Управление:**
    - Левая кнопка мыши: открыть клетку.
    - Правая кнопка мыши: установить флажок.
    - Правая кнопка мыши (двойное нажатие): снять флажок.
5.  **Интерфейс:**
    - Графический интерфейс на Windows Forms с использованием `DataGridView` и изображений.
    - Наличие главного меню с выбором сложности.
6.  **Таймер:**
    - Отсчёт времени начинается с первого клика по полю.
    - Время отображается в секундах.
7.  **Сохранение данных:**
    - Сохранение рекордов и статистики в файл `records.json`.
    - Структура JSON должна быть удобочитаемой, с русскими названиями полей.
    - При отсутствии файла он должен создаваться автоматически.
8.  **Технологический стек:**
    - Язык программирования: C#.
    - Платформа: .NET Framework 4.7.2+.
    - Библиотека для работы с JSON: Newtonsoft.Json.

#### 5. Руководство администратора

##### 5.1. Установка и запуск
1.  **Требования к системе:**
    - Операционная система: Windows 7/8/10/11.
    - Установленный .NET Framework 4.7.2 или выше (обычно уже установлен в Windows 10/11).
2.  **Установка приложения:**
    - Скачайте архив с проектом.
    - Распакуйте архив в любую папку на компьютере.
3.  **Настройка изображений:**
    - Убедитесь, что в папке с исполняемым файлом (обычно `bin\Debug\` или `bin\Release\`) присутствует папка `images`.
    - В папке `images` должны находиться следующие файлы: `bomb.png`, `empty.png`, `flag.png`, `one.png`, `two.png`, `three.png`, `four.png`, `unknown.png`.
4.  **Запуск игры:**
    - Для запуска из исходного кода откройте файл решения (`SaperXoxoev.sln`) в Visual Studio и нажмите `F5`.
    - Для запуска готового приложения перейдите в папку `bin\Release\` или `bin\Debug\` и дважды кликните по файлу `SaperXoxoev.exe`.

##### 5.2. Файловая структура проекта
- **`SaperXoxoev/`**: Корневая папка проекта.
  - **`SaperXoxoev.sln`**: Файл решения Visual Studio.

  - **`FormGame1.cs`**: Код и логика игрового поля.
  - **`Cell.cs`**: Класс, описывающий состояние одной клетки.
  - **`GameEngine.cs`**: Класс, содержащий всю игровую логику.
  - **`RecordsData.cs`**: Класс-модель для данных рекордов.
  - **`RecordsManager.cs`**: Класс для загрузки и сохранения рекордов в JSON.
  - **`Program.cs`**: Точка входа в приложение.
  - **`images/`**: Папка с графическими файлами для интерфейса.

#### 6. Руководство пользователя

##### 6.1. Основные действия
1.  **Запуск и выбор сложности:**
    - Запустите `SaperXoxoev.exe`.
    - В главном меню выберите уровень сложности из выпадающего списка:
      - **Новичок:** 10 мин.
      - **Любитель:** 13 мин.
      - **Профессионал:** 16 мин.
      - **Мастер:** 52 мины.
    - Нажмите кнопку **«Играть»**.
2.  **Игровой процесс:**
    - Кликните **левой кнопкой мыши** по любой клетке, чтобы открыть её. Это будет ваш первый ход, он всегда безопасен.
    - Если на клетке появилась **цифра** (1, 2, 3 или 4), значит, рядом с ней находится ровно столько мин.
    - Если клетка осталась **пустой**, все соседние с ней пустые клетки откроются автоматически.
    - Чтобы отметить подозрительную клетку как мину, кликните по ней **правой кнопкой мыши** (появится флажок 🚩). Повторный клик правой кнопкой снимает флажок.
3.  **Окончание игры:**
    - **Поражение:** Если вы открыли клетку с миной, игра заканчивается. Все мины будут показаны. Вам будет предложено начать игру заново или выйти.
    - **Победа:** Если вы открыли все клетки, кроме мин, игра заканчивается победой. Записывается ваше время. Если оно стало рекордным, вы увидите уведомление.

#### 7. Руководство программиста

##### 7.1. Структура проекта
- **`SaperXoxoev.sln`**: Файл решения Visual Studio, объединяющий все проекты.
- **`FormMenu.cs`**: Код главного меню. Отвечает за выбор уровня сложности, запуск игры и отображение статистики.
- **`FormGame1.cs`**: Код игровой формы. Содержит игровое поле, обработчики кликов мыши, рекурсивную функцию открытия клеток, таймер и взаимодействие с рекордами.
- **`FormGame1.Designer.cs`**: Автоматически сгенерированный код дизайна игровой формы (содержит элементы управления).
- **`Cell.cs`**: Класс-модель одной клетки. Хранит состояние: есть ли мина, открыта ли клетка, стоит ли флаг, сколько мин рядом.
- **`GameEngine.cs`**: Класс игровой логики. Содержит двумерный массив клеток, методы генерации мин, подсчёта мин вокруг клетки и сброса поля.
- **`RecordsData.cs`**: Класс-модель для хранения рекордов и статистики. Используется для сериализации в JSON.
- **`RecordsManager.cs`**: Статический класс для загрузки и сохранения рекордов. Работает с файлом `records.json` через библиотеку Newtonsoft.Json.
- **`Program.cs`**: Точка входа в приложение. Запускает главную форму `FormMenu`.
- **`images/`**: Папка для хранения графических файлов (`.png`) для отображения клеток.

##### 7.2. Основные модули

- **`FormMenu`**:
  - Загрузка и отображение главного меню.
  - Обработка выбора уровня сложности через `ComboBox`.
  - Запуск игровой формы `FormGame1` с передачей количества мин.
  - Отображение статистики через кнопку "Статистика".

- **`FormGame1`**:
  - Создание и настройка игрового поля `DataGridView` с изображениями.
  - Обработка событий мыши:
    - `CellContentClick` (левый клик) — открытие клетки.
    - `CellMouseClick` (правый клик) — установка/снятие флажка.
  - **`OpenEmptyCells()`** — рекурсивная функция для открытия пустых областей.
  - **`CheckVictory()`** — проверка условий победы.
  - **`Defeat()`** — обработка поражения.
  - **`NewGame()`** — сброс поля для новой игры.
  - Таймер `timer1` для отсчёта времени.

- **`GameEngine`**:
  - **`field`** — двумерный массив объектов `Cell`.
  - **`GenerateBombs()`** — генерация мин после первого клика с гарантией безопасности.
  - **`CountBombsAround()`** — подсчёт мин вокруг указанной клетки.
  - **`ResetField()`** — полный сброс состояния поля.

- **`RecordsManager`**:
  - **`LoadRecords()`** — загрузка данных из `records.json`.
  - **`SaveRecords()`** — сохранение данных в `records.json`.
  - **`UpdateRecord()`** — обновление рекорда для конкретного уровня сложности.
